# tasks

红莓任务执行模块，提供管理员任务管理、Shell 步骤调度、Webhook、运行历史与实时日志。后端通过 boot 生命周期运行，认证使用 auth；任务及运行记录保存为文件，不需要 SQL 数据库。

前端通过模块默认装配提供 `/` 任务页面与 `/runs` 运行历史；通用控件由正式 ui 模块提供。Go HTTP API 是契约源，客户端由消费应用的 CLI 生成并传入模块 Provider。

使用前读取 [使用规范](README.LLMS.md)。独立后端开发示例位于源码仓库的 examples/basic，开发示例不随模块安装。

## 执行与数据边界

Shell 以服务进程身份运行，不是隔离沙箱。管理员必须只配置可信脚本和目录；Webhook 令牌等同于该任务的执行权限。

任务文件位于配置的任务数据目录下的 `tasks/`，执行状态和原始日志位于该目录下的 `runs/`。同一数据目录只允许一个进程使用。运行数据与运行配置独立于发布产物保存。

Go 契约以 `TaskInput.SchedulingPolicy` 表达同名调度策略，以 `Run.TaskName` 表达运行所属任务名称；HTTP 与历史文件继续使用 `queue`、`name` 字段，前端客户端遵循该 JSON 协议。

同名任务按 wait 或 terminate 策略串行；受理时冻结配置。取消、超时及正常命令退出均清理该进程组内残留进程。异常退出后未完成记录恢复为 interrupted，不自动重执行。

运行终态保存失败时保留内存结果并重试落盘，存储恢复不重跑命令。内存终态尚未落盘而进程异常退出时，不能保证恢复该终态。历史清理和日志轮转由部署方管理。

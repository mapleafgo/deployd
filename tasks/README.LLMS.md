# tasks 使用规范

## 接入任务能力

约定：

- 使用 CLI 生成装配的应用直接使用已装配的模块，不重复注册 `backend.Module`。独立后端组合须提供模块所依赖的 boot、auth、cache 和配置加载环境。
- 通过统一配置选择任务数据目录；同一目录只允许一个服务进程使用。部署方保管任务令牌、脚本、变量及日志，业务操作必须来自可信管理员。
- Webhook 入口采用任务令牌独立授权。使用 auth 默认登录策略时，必要策略配置须排除 `/api/hooks/**` 与兼容入口 `/hook/**` 的登录检查；这不免除模块自己的令牌核验。
- 本模块管理接口只允许配置来源的 admin 应用管理员身份。安装其他账户来源不自动赋予任务管理权限。

公共入口：

- [backend.Module](backend/redberry_module.go)：任务服务、HTTP API 与运行生命周期装配。
- [backend.Config](backend/redberry_config.go)：统一配置声明，配置组由模块身份推导。

## 配置与执行任务

约定：

- 运行环境提供可执行的 `/bin/bash`；模块启动时检查，缺失或不可运行则启动失败。任务使用非交互 Bash，shebang 不切换解释器；初始化命令在脚本中显式执行。
- 配置完整任务和至少一个步骤；步骤的每个命令数组元素在独立 Bash 中运行，不能依赖前一个元素留下的 Shell 状态。已有任务使用 Bash 执行，升级前复验原脚本，不依赖 sh 的实现细节。
- 任务环境变量供本任务所有步骤继承，步骤变量仅覆盖所属步骤的同名变量；删除覆盖恢复继承，空字符串是覆盖值。触发白名单变量按既有契约拥有更高优先级。
- 任务、步骤和触发输入不能声明 `BASH_ENV`、`ENV`、`SHELLOPTS`、`BASHOPTS`、`POSIXLY_CORRECT`；这些启动控制项及导出的 Bash 函数不会从服务环境传入执行进程。违规输入返回 `shellEnvReserved` 字段错误。旧任务中的合法启动控制变量声明可读取但执行时忽略，再次保存前移除这些声明。
- 受理后任务采用配置快照；修改任务不影响已受理运行。活动任务须先取消或等待完成才能删除，删除任务保留运行历史。
- 同名调度策略由既有 `queue` 字段选择 `wait` 或 `terminate`；超时从实际执行开始计算。变量覆盖只接收任务或步骤中已声明的变量。
- 取消或超时会终止命令进程组。需要常驻的服务交给外部服务管理器，而非作为任务后台进程保留。
- 输入校验一次返回字段问题：顶层 `code` 为 `invalidTask`，`errors[]` 提供稳定 `code`、`location` 与按请求语言生成的安全 `message`，不返回原始输入值。字段路径沿用 Huma 的 `body.timeout`、`body.steps[0].workdir` 等形式；界面按身份翻译并按位置回填，无法对应字段的问题保留为表单级反馈。存储损坏返回安全故障反馈，不当作输入错误。

公共入口：

- [Step、TaskInput、Task、Run](backend/tasks.go)：任务输入与运行状态契约；HTTP 请求类型和约束由 Go API 生成。

## 使用任务页面

约定：

- 使用 CLI 默认装配接入页面、Provider 和翻译资源；应用提供同一运行环境中的 i18n、QueryClient、HTTP 和认证环境，不补写任务专属 API 映射。
- 本模块占用任务首页与运行历史路由，消费应用应避免其他页面占用相同路径。
- 独立组合页面时通过前端包公开入口使用；在已提供 UI、Query 和认证环境的组件树中挂载本模块 Provider。模块资源保留自己的命名空间。
- 编辑已有任务且未改脚本文本时保留原始命令数组；修改脚本后按一个带失败即停前缀的 Shell 脚本提交。
- 默认创建流程使用具名步骤与 Bash 代码字段；任务变量和步骤变量分别配置，折叠、扩展编辑和语言变化保留输入。代码高亮与补全不等于静态检查或执行成功。
- 管理员关闭或离开未保存的表单时确认是否丢弃；草稿不自动持久化，确认丢弃或创建成功后结束编辑。
- 搜索框标题与说明按 ui 使用规范的字段语义约定执行：任务页的 `q` 同时匹配任务名称与说明，标题用“关键词”、说明用“任务名称或说明”；运行历史的 `q` 只匹配任务名称，标题用“任务名称”、说明给出实际匹配方式（包含匹配、不区分大小写）。列表标题携带任务名时，运行历史的 `name` 与 `q` 同时生效。

公共入口：

- [createRoutes](frontend/index.ts)：声明任务、历史路由及菜单贡献。
- [createProvider、ModuleContext](frontend/module.tsx)：接收生成客户端与应用共享运行环境。
- [TasksPage](frontend/tasks.tsx)：任务列表与编辑入口；`ModulePage` 保留为兼容别名。
- [RunsPage](frontend/runs.tsx)：运行历史与日志入口。
- [translations、moduleNamespace](frontend/messages.ts)：模块翻译资源与隔离命名空间。

## 消费运行日志

约定：

- 日志请求使用已认证会话的带请求头 fetch，不将管理员 Access 凭据放入 URL。
- 自行消费 SSE 时按 Base64 原始字节和累计字节偏移续传，使用流式 UTF-8 解码；连接期限到达后的重连不代表任务重新执行。
- 完整原始日志保存在服务端，前端展示限额不代表日志文件被截断。部署方负责日志保留与清理策略。
